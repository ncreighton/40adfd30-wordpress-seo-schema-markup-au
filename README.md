WordPress plugin that automatically generates JSON-LD schema markup for all post types including Articles, FAQPage, HowTo, Product, LocalBusiness, BreadcrumbList, and Review. Detects content type from post category and heading structure using pattern matching. Outputs valid Schema.org markup validated against Google Rich Result Test standards. Includes bulk retroactive schema injection for existing posts, a schema preview panel in the editor, and a site-wide schema health dashboard showing coverage percentage by type.

== Description ==

WordPress plugin that automatically generates JSON-LD schema markup for all post types including Articles, FAQPage, HowTo, Product, LocalBusiness, BreadcrumbList, and Review. Detects content type from post category and heading structure using pattern matching. Outputs valid Schema.org markup validated against Google Rich Result Test standards. Includes bulk retroactive schema injection for existing posts, a schema preview panel in the editor, and a site-wide schema health dashboard showing coverage percentage by type.

**Features:**

* Core functionality

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > WordPress SEO Schema Markup Auto-Generator Plugin
